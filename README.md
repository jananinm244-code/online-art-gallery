# 🎨 ArtNest — Online Art Gallery

ArtNest is an aesthetic online art gallery and marketplace where artists can showcase and sell their sketches, paintings, portraits, and digital artwork. Users can explore, search, filter, save, view, and purchase artworks through an interactive gallery interface.

## ✨ Features

- 🎨 30+ artworks to explore
- 🔍 Search artworks by name or artist
- 🏷️ Filter by artwork category
- ❤️ Save favourite artworks
- 🖼️ View detailed artwork information
- 💰 Display artwork prices
- 🛒 Interactive purchase option
- 👩‍🎨 Featured artist section
- 📤 Sell and publish your own artwork
- 💾 Favourite artworks saved using LocalStorage
- ✨ Smooth animations and interactive UI
- 📱 Fully responsive design
- 🌈 Aesthetic pastel colour theme

## 🖌️ Artwork Categories

- Painting
- Sketch
- Watercolor
- Digital Art
- Portrait

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Responsive Web Design
